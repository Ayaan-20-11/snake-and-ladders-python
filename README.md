# Snake and Ladders Game 🎲

A multiplayer Snake and Ladders game built using Python and Tkinter.

## Features

- Supports 2–4 players
- Custom player names
- Interactive Tkinter GUI
- Snakes and ladders mechanics
- Dice rolling system
- Winner tracking
- Play Again functionality

## Technologies Used

- Python
- Tkinter
